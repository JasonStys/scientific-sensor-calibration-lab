# Validation strategy and measured evidence

## What is verified

Every report compares the real C# fit's coefficient/covariance/status fields with an independent exact-rational Python implementation of known-response-variance linear WLS. C# uses centered double moments; reference uses exact raw normal equations. Analytical inverse/covariance/scaling tests complement differential comparisons. These verify the stated equations and contracts, not physical calibration, statistical assumptions or certified coverage. No real sensor or reference-standard experiment was performed.

Python tests cover all162 finite presets,60 deterministic generated differential fits, explicit coefficients/covariance/inverse uncertainty, slope sign, missing reference, age boundary, nonlinearity, missing/clipped/outside-span samples, held-out separation, schema/range/UTF/depth/duplicate/size/maximum records, actual native parser rejection, process failures/malformed native output, failure injection, inert exports, immutable/idempotent/capped SQL with explicit close, CLI create-only replay and real HTTP security/routes/errors. Native self-tests independently check a perfect-line analytical fit, covariance, uncertainty scaling, degenerate/span/flat cases and parser rejection. Native code coverage is **not measured** by Python coverage; do not conflate them.

Browser tests use the actual production build in Chromium/Firefox/WebKit: native fit/chart rendering, accepted-setting downloads, all four file formats, missing values, expiration, unsupported nonlinearity, diagnostic mismatch, stale/failed/malformed responses, inert hostile provenance, keyboard/mobile layout, axe checks and finite read-only API enforcement. Automated accessibility is not a full assistive-technology audit.

## Correction history

The first full pass found a synthetic unequal-uncertainty preset whose maximum multiplier exceeded the declared input limit. The preset was corrected; strict limits were not relaxed and every finite combination is tested. Oversized native-parser test IDs also exceeded Windows path constraints in pytest; descriptive short IDs preserve the same byte payloads. The Windows .NET formatter initially could not connect to its build-host pipe in the sandbox; the same pinned formatter passed with normal process permissions, without disabling protections. Local NuGet downloads use task-local cache paths. Runtime notices were not automatically copied by self-contained publish, so packaging now retrieves the actual notices from the exact runtime-version NuGet pack and requires them in the frozen app. RID-specific publishing uses a separate ignored lock path, preserving the generic dependency-free source lock. The Windows frozen app passed real native/reference, missing-value export, replay, SQL and HTTP smoke checks. No test skip, relaxed coverage gate or hidden nonfatal failure was used.
