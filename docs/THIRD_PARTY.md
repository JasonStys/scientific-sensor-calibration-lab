Python runtime uses only CPython's standard library (including SQLite and Fraction); C# uses only the .NET base class library, with an empty NuGet package graph. Source requires the stable SDK pinned in `global.json`. The C# app executable is included as a binary so its Unix executable mode survives freezing. OS/architecture-specific .NET runtime files vary across runners and are not universal binaries.

Linux additionally retains Ubuntu/Debian GCC runtime copyright/GPL notices for potentially collected runtime libraries. These notices do not change the MIT license on original project code.
